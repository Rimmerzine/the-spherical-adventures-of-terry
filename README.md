# The Spherical Adventures of Terry

The spherical adventures of terry is a small game in development.

## After cloning the repository

Ensure you have npm installed.

Run `npm install` to install the dependencies.

Run `npx tsc` to compile the typescript into javascript for the running server.
You can also run `npx tsc -w` to compile the typescript into javascript for the running server whilst also updating when files are updated.

Run `npm run start` to start a local web server.

Open <http://localhost:5407> to connect to the local web server and access the game.
